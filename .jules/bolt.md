## 2023-10-27 - Global Event Listener Optimizations
**Learning:** In vanilla JS setups, global event listeners (like on `document` for clicks or `details` for toggle events) that unconditionally execute DOM queries (e.g., `querySelector` or `querySelectorAll`) inside their callbacks can cause unnecessary layout thrashing and performance overhead, especially as the DOM grows. This is a common pattern to close popups when clicking outside.
**Action:** Always wrap DOM queries and mutations inside global event listeners with a state check (e.g., checking if the element actually has an `open` class or attribute first). Additionally, cache static or infrequently changing NodeLists (like all `<details>` elements) outside the event listener to avoid repeated `querySelectorAll` calls on every interaction.
