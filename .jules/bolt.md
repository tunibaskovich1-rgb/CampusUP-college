## 2024-10-24 - Avoid unconditional DOM queries in global event listeners
**Learning:** In static sites with vanilla JS, performing unconditional DOM queries (like `querySelector`) inside global event listeners (like `document.addEventListener('click')`) can cause unnecessary reflows/layouts and slow down page interactions, especially when querying multiple elements on every click anywhere on the page. Also, repeatedly querying the same static NodeList inside event callbacks (e.g. `document.querySelectorAll('details')` inside a `toggle` event) wastes CPU cycles.
**Action:** Always check if the target elements are currently active/open before performing DOM queries or attribute updates inside global event listeners. Query and cache static node lists globally instead of inside event callbacks.
