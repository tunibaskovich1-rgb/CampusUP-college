## 2024-05-18 - Unrestricted Global Event Handlers
**Learning:** In the CampusUP College codebase, global event listeners (like the document `click` listener for closing dropdowns) were executing expensive DOM queries (`querySelector` and `setAttribute`) on every single click on the page, regardless of whether a dropdown was actually open. Furthermore, node lists for `details` tags were being repetitively queried inside event listeners for *every* toggle event, exacerbating layout thrashing and DOM query overhead.
**Action:** Always verify if a global event listener has early exit conditions (like checking `classList.contains('open')`) before executing further logic. Ensure node lists queried via `querySelectorAll` are cached outside of event listeners when the collection of elements won't change dynamically.
