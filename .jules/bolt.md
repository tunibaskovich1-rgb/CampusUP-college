## 2026-06-02 - Optimize global event listeners in Vanilla JS
**Learning:** In a vanilla JS environment, attaching global event listeners (like `document.addEventListener('click')`) that loop over elements and perform unconditional DOM operations (e.g., querying `.dropdown-toggle` inside a loop for every click on the page) causes unnecessary layout thrashing and performance overhead, especially as the DOM grows.
**Action:** Always check if the target elements are active (e.g., checking if `.open` class exists) before performing DOM queries or state updates inside high-frequency global event listeners. Additionally, cache static NodeLists globally rather than querying them repeatedly inside event callbacks (e.g., `querySelectorAll('details')` inside the `toggle` listener).
