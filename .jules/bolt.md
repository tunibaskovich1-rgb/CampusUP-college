## 2024-05-24 - Initial Review
**Learning:** Found an O(n²) behavior in the FAQ accordion toggle script. When one `<details>` element opens, the script uses `querySelectorAll('details')` inside the event listener to find all other `<details>` elements and close them. This means for $N$ details elements, opening one causes an $O(N)$ query and loop, which isn't necessary. If there are many details, this is inefficient.
**Action:** Optimize the details toggle to cache the list of details elements outside the event listener to avoid repeated DOM queries.
## 2024-05-24 - DOM Query Optimizations
**Learning:** Found an $O(n^2)$ behavior in the FAQ accordion toggle script. When one `<details>` element opens, the script uses `querySelectorAll('details')` inside the event listener to find all other `<details>` elements and close them. This means for $N$ details elements, opening one causes an $O(N)$ query and loop, which isn't necessary. Additionally, a global click listener iterates over all dropdowns and removes the 'open' class regardless of whether it's actually open, causing unnecessary DOM operations.
**Action:** Always cache static node lists like `document.querySelectorAll('details')` outside of event listeners. Before modifying DOM classes or attributes on a collection of elements, check if the modification is necessary (e.g., check `classList.contains('open')` before removing it).
