## 2026-05-29 - Unconditional DOM operations in global event listeners
**Learning:** Found a performance bottleneck where a global `click` event listener was executing `dropdown.classList.remove('open')` and `dropdown.querySelector('.dropdown-toggle')` on *every single click* anywhere on the page, for *every* dropdown component, regardless of whether any dropdown was actually open.
**Action:** When implementing global event listeners (like 'click outside to close'), always check if the target elements are currently active/open (e.g., `element.classList.contains('open')`) before performing DOM queries (`querySelector`) or attribute updates (`setAttribute`, `classList.remove`). Also, query common node lists like `querySelectorAll('details')` once and cache them instead of re-querying inside event callbacks when the list of elements is static.
