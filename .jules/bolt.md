## 2024-07-21 - Caching DOM queries and state checks in global event listeners
**Learning:** In vanilla JS apps, global document event listeners (like click handlers that close dropdowns) fire on every click anywhere on the page. Doing expensive DOM queries like `dropdown.querySelector('.dropdown-toggle')` on *every* click for *every* dropdown component, regardless of whether it's open, blocks the main thread unnecessarily. This becomes a major bottleneck as the number of interactive components grows.
**Action:** Always check the element's current state (e.g. `dropdown.classList.contains('open')`) before executing further DOM queries or state updates within global event loops. Also cache static NodeLists (`document.querySelectorAll`) outside of event listeners instead of re-querying the DOM inside them.
