## 2026-06-02 - Consistent Keyboard Focus Visible Styles
**Learning:** Explicitly styling `:focus-visible` with a distinct brand color outline (e.g., `#2563eb`) provides a vital high-contrast visual cue for keyboard navigation without affecting mouse users, improving accessibility for all interactive elements.
**Action:** Use `:focus-visible` with `outline` and `outline-offset` on reusable interactive elements like links and buttons instead of standard `:focus` to balance aesthetics and accessibility.
