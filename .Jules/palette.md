## 2026-07-12 - Universal Focus Styles
**Learning:** Vanilla CSS codebases often lack default, consistent focus indicators. Adding a universal `*:focus-visible` rule is a highly effective, low-effort way to instantly improve keyboard accessibility across all interactive elements without negatively impacting mouse/touch users.
**Action:** Always check for existing focus styles. If absent, propose a universal `:focus-visible` rule using the brand's primary color to establish a baseline of accessibility.
