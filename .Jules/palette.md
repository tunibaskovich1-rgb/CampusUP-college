## 2024-06-29 - Global Focus Visible Outline
**Learning:** Using a global `*:focus-visible` rule provides a consistent keyboard accessibility indicator without affecting mouse users, which is essential for ensuring all interactive elements are navigable by keyboard. Setting an `outline-offset` ensures the focus ring is clear and doesn't overlap with the element's boundaries.
**Action:** Default to using `*:focus-visible` for keyboard accessibility, ensuring high contrast using brand colors (like `#2563eb`), rather than strictly targeting specific elements.
