## 2024-05-24 - Universal Focus-Visible Pattern
**Learning:** Native focus outlines vary widely across browsers and elements (especially on custom details/summary or custom dropdowns). A universal *:focus-visible ensures consistent, brand-aligned keyboard accessibility across the entire application without needing to specifically target every new component.
**Action:** Apply a universal *:focus-visible with a brand-aligned color and an appropriate outline-offset as a baseline in global CSS to guarantee all interactive elements have visible focus states for keyboard users.
